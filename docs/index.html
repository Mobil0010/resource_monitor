01 · SENSOR ACCESS

PawnIO · 하드웨어 온도 센서

CPU와 C 드라이브처럼 Windows가 기본적으로 공개하지 않는 하드웨어 온도를 읽는 데 사용합니다. 처음 실행할 때 별도의 설치 창과 관리자 권한 요청이 나타날 수 있습니다.

설치하지 않아도 기본 모니터링은 작동하지만 일부 온도가 표시되지 않을 수 있습니다.

02 · GAME METRICS

PresentMon · FPS와 프레임 시간

Steam 게임 팝업에서 초당 프레임과 프레임 시간(ms)을 측정할 때 사용합니다. Windows 설치 마법사와 Portable ZIP에 함께 포함되어 별도로 설치할 필요가 없습니다.

FPS 또는 프레임 시간 표시를 켠 게임이 실행 중일 때만 측정에 사용합니다.

WHAT IT TRACKS

필요한 정보만, 실시간으로.

01

시스템과 온도 모니터링

CPU 전체·코어별 사용률, GPU, 메모리, 디스크 용량과 CPU·GPU·C 드라이브 온도를 한 화면에서 확인하고 1~10초 간격으로 갱신할 수 있습니다.

02

프로세스 & 네트워크

실행 중인 프로세스를 검색하고 CPU 점유율 순으로 확인하며, 다운로드·업로드 속도와 최근 사용 기록을 실시간 그래프로 추적합니다.

03

자유롭게 설정하는 팝업

표시 항목과 미니 그래프, 모니터, 화면 위치, 크기, 배경 투명도를 따로 설정할 수 있습니다. 팝업은 클릭을 가로채지 않아 뒤의 게임과 앱을 그대로 조작할 수 있습니다.

04

Steam 게임 연동

로컬 Steam 라이브러리를 자동 또는 수동으로 찾고 전체·선택 게임을 감지합니다. 공통 또는 게임별 팝업 설정을 적용하고 게임 종료 후 기존 팝업을 자동으로 복원합니다.
